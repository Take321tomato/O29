# O29

スマホ（Claude アプリ / claude.ai/code）から Claude Code を使って開発するためのリポジトリです。

## スマホから使う手順

1. **GitHub 連携**: claude.ai の設定 → Connectors で GitHub を接続し、Claude GitHub App をこのリポジトリにインストールする。
2. **セッション開始**: スマホの Claude アプリ（または ブラウザで claude.ai/code）→「Code」→ リポジトリ `take321tomato/o29` を選んで指示を送る。
3. **作業の流れ**: Claude がクラウド上のコンテナでコードを編集 → `claude/...` ブランチにコミット & push → 必要なら PR を作成。
4. **確認**: GitHub アプリ / ブラウザでブランチや PR を確認し、問題なければ main にマージ。

## 保存先について（重要）

- 作業は **クラウド上の一時コンテナ** で行われ、スマホ本体（ローカル）には保存されません。
- コンテナはセッション終了や一定時間の非操作で破棄されます。**残したいものは必ず GitHub に push** してください（push されたものが正式な保存先です）。
- 自分の PC のファイルを扱いたい場合は、PC 側の Claude デスクトップアプリで Remote Control を有効にすると、クラウドセッションから PC のフォルダに接続できます。

## 環境設定

- 環境: `Default`（パッケージレジストリ npm / PyPI 等にはアクセス可）
- 外部 API のホスト許可や API キーが必要になったら、その時点で環境設定に追加します。
